# Application Icons

This directory contains the icons for the Compliance Tracker desktop application.

## Required Icons

1. **icon.ico** - Windows application icon (256x256 or larger)
2. **icon.png** - Application icon for various uses (512x512 recommended)
3. **tray-icon.png** - System tray icon (16x16 or 32x32)

## Creating Icons

You can create these icons using:
- Online tools like https://www.icoconverter.com/
- Design tools like Figma, Adobe Illustrator, or Inkscape
- Icon generators

## Temporary Solution

For now, you can use placeholder icons. The application will work without custom icons, but it's recommended to add proper branding icons before distribution.

To add icons:
1. Create or download your icons
2. Place them in this directory with the exact names above
3. Rebuild the application

## Icon Specifications

- **icon.ico**: Windows ICO format, multiple sizes (16, 32, 48, 256)
- **icon.png**: PNG format, 512x512px, transparent background
- **tray-icon.png**: PNG format, 16x16 or 32x32px, simple design for visibility
