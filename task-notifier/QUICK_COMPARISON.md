## Example Workflow

### Morning Routine
1. **Desktop pop-up appears**: "High Priority: Monthly Report due in 2 days"
2. **Click notification**: Opens web dashboard
3. **Review task**: Check details and requirements
4. **Mark in progress**: Updates status
5. **Slack reminder**: Backup notification on phone

### Managing Tasks
1. **Open web dashboard**: See all 11 projects
2. **Upload Excel**: Import latest task list
3. **Set recurring**: Monthly reports auto-create
4. **Prioritize**: Mark critical tasks
5. **Close browser**: Desktop agent keeps running

### Getting Reminded
1. **Agent checks hourly**: Scans for due tasks
2. **Calculates priority**: Critical tasks first
3. **Sends notification**: Desktop pop-up + Slack
4. **You respond**: Complete, snooze, or view
5. **Repeat**: Every 2 days until done
